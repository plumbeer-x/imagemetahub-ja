# メンテナンス手順：本体がバージョンアップしたとき

Image MetaHub 本体のバージョンが上がったら、書き変える場所はこのファイルの通りです。

## まず試すだけなら（書き変え不要）

パッチャーは、検証済みでないバージョンでも警告を出した上でそのまま実行できます（`y` で続行）。
UI の文字列はバージョン間でほとんど変わらないので、多くの場合はそのままで日本語化できます。
新しく増えた画面・文言だけ英語が残ります。置換が 0 件なら自動で中止するので、壊れたパッチにはなりません。

## 正式対応にする手順

### 1. `patcher/main.go` — 検証済みバージョンを追加

先頭の方にある一覧に、確認が取れたバージョンを1行足します。

```go
var testedVersions = []string{
	"0.23.0",
	"0.24.0", // ← こんなふうに追加
}
```

### 2. `patcher/dict.json` — 新しい文字列があれば追加

新しいバージョンで増えた UI 文言があれば、英文字列 → 日本語の対応を足します。
既存の訳を消す必要はありません（無くなった文字列は単に使われないだけです）。

### 3. `README.md` — 対応環境を更新

タイトルと「対応環境」に、新しい検証済みバージョンを書き足します。

### 4. ビルドし直す

```bat
cd patcher
build.bat
```

`imagemetahub-ja-patch.exe` が作り直されます。

### 5. 新しい Release を出す

- タグはパッチ側の番号を上げます（例: `v1.1.0`）
- 新しい exe を Release に添付します
- 本文には「Image MetaHub v○.○.○ に対応」と書きます

## 書き変えなくていい場所

- 置換の仕組み自体（`main.go` の置換処理）はバージョンに依存しません
- バンドルのファイル名はバージョンごとに変わりますが、パッチャーはファイル名ではなく「dist 内の JS かどうか」で判定しているので触らなくて大丈夫です
