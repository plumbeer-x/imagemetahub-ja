# Image MetaHub 日本語化パッチ

[Image MetaHub](https://github.com/LuqP2/Image-MetaHub) の UI を日本語化する、非公式のファンパッチです。
公式には多言語対応の仕組みがないため、このパッチャーがお使いの PC 上で `app.asar` 内の表示文字列を辞書で置換します。

> **注意**: これは非公式パッチです。Image MetaHub 公式とは関係ありません。
> パッチ適用は自己責任でお願いします（適用前に自動でバックアップを作成します）。

## 対応環境

- Image MetaHub **v0.23.0** で検証済み（インストーラー版のみ）
- Windows 10 / 11（64bit）
- Portable 版は対象外です（パッチが残らないため）

検証済みでないバージョンでも、パッチャーが警告を出した上で日本語化を試せます。
文字列が一致しない場合は、書き換えずに自動で中止します。
本体の更新に追従する方法は [MAINTAINING.md](MAINTAINING.md) にあります。

## 使い方

1. [Releases](../../releases) から `imagemetahub-ja-patch.exe` をダウンロード
2. Image MetaHub を終了する
3. `imagemetahub-ja-patch.exe` をダブルクリックし、Enter を押す
   - インストール先は自動で探します（標準: `%LOCALAPPDATA%\Programs\Image MetaHub`）
   - 見つからない場合は、exe をインストールフォルダ内の `resources` フォルダに置いて実行するか、`app.asar` を exe にドラッグ＆ドロップしてください
4. 初回は元の `app.asar` を `app.asar.bak` として自動バックアップしてから書き換えます
5. Image MetaHub を起動すると、日本語 UI になっています

## 元に戻す（英語版に復元）

パッチャーをもう一度実行すると「すでに日本語化されています」と表示されるので、`y` を入力するとバックアップから復元します。
手動で戻す場合は、`resources` フォルダ内の `app.asar.bak` を `app.asar` にリネームしてください。

## 日本語化の範囲

- 主要画面が対象です：ヘッダー／タブ、サイドバー、フィルター、画像詳細、設定画面、共通ボタンなど（置換 732 か所、辞書 327 語）
- 一部のトースト通知や細かいメニューなど、英語のまま残る箇所があります
- Prompt / Seed / CFG / Sampler などの専門用語は、慣例に合わせて英語のままにしています

## 仕組みと安全性

- 置換するのは **UI の表示位置にある文字列だけ** です。内部のキー名、ショートカットキー名、データの値には触れません
- ライブラリ系・ワーカー系のバンドル（three.js など）は対象外です
- 書き換えたファイルの整合性ハッシュ（SHA-256）は再計算するので、`app.asar` として正しい形式を保ちます
- 日本語化済みの `app.asar` 本体は配布していません。各ユーザーの PC 上で書き換える方式なので、本体の再配布にはなりません

## 注意点

- Image MetaHub をアップデートすると上書きされ、英語に戻ります。そのバージョン用のパッチが必要です
- 起動しなくなった場合は、上記の手順で復元してください

## ソースからビルド

Go 1.24 以上が必要です。

```bat
cd patcher
go build -o imagemetahub-ja-patch.exe .
```

翻訳辞書は `patcher/dict.json`（英文字列 → 日本語の対応表）です。訳の追加・修正はこのファイルへの Pull Request を歓迎します。
